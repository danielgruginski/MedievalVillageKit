# Notes for AI agents

- **Building levels in Unity** with the package (rooms from plans, the cave / dungeon / house / connector
  generators, chains of maps streamed as one world, the walk tests that prove a level is playable):
  [unity/com.danielgruginski.medievalkit/Documentation~/LEVEL_BUILDING.md](unity/com.danielgruginski.medievalkit/Documentation~/LEVEL_BUILDING.md).
- **Working on the kit itself** (the Blender code in `src/`, the exporter, the package's internals): read
  [HANDOFF.md](HANDOFF.md) first (working agreements, open issues, the checks to run), then
  [docs/UNITY_EXPORT.md](docs/UNITY_EXPORT.md) for the Unity side.
- Someone usually has Blender and the Unity editor open and watches them: build in scenes of your own, never replace
  or close theirs.
